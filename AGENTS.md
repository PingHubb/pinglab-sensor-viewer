# Sensor viewer conventions

Use the full reported channel counts, without an automatic −1. ACM5 is 20 × 20 (400 taxels). Keep reference-column exclusion off by default and verify the grid before acquisition.

Preserve the user's display defaults: Smooth 3D and colour range ±500. Keep English and Simplified Chinese UI translations in sync, including dynamic messages and canvas labels. Language changes must not reconnect the sensor or interrupt recording.
