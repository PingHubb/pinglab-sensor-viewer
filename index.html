PINGLAB / QUICK START
A sensor workspace. In your browser.
  1. Open this website in desktop Chrome or Edge over HTTPS.
  2. Connect your USB serial sensor. Close the desktop viewer and Arduino Serial Monitor so the port is free.
  3. Choose the baud rate and grid, then click Connect sensor and select your device.
  4. Leave the sensor untouched and press Update Calibration.
  5. Pick a taxel, explore the six views, or record all taxels to CSV. Stop recording and download both CSV and JSON.
Auto grid uses all reported drive and sense channels. Enable ‘Exclude last column’ only if your sensor has a reference column. Verify orientation with a known corner. Custom grids support up to 1,600 taxels.
Live USB access requires Web Serial. Firefox, Safari and most mobile browsers cannot connect here. Demo and plots do not require hardware. A USB adapter driver may still be needed.
This viewer supports the same serial/Arduino/ESP32 firmware as the Windows v0.2.2 app. Direct Goodix USB/HID, robots and firmware flashing are outside its scope.
Negative signals stay negative. Percent values are undefined when baseline is zero. Graph history holds 3,000 frames and clears after calibration. Freeze pauses only the graph. Downloads stay local; no sensor data is sent to GitHub.
Browser port permission, file downloads and tab lifetime differ from the desktop app. Real sensor behavior needs verification on your hardware. Keep this tab visible and the computer awake during acquisition.
